# AI, catalog and styling — Astra 1 only
Own feature/catalog-stylist and the assigned AI/catalog module only. Reuse frozen request/response schemas. Rank only known, entitled catalog entries with stable identifiers; track why every result was selected. Keep sponsorship disclosures and ranking policy separate. Prefer deterministic rule-based baselines before introducing model inference. Use seeded evaluation sets for representative inputs, no-match, inconsistent attributes, missing metadata and sponsored content. Never invent availability, sizing, rights, prices or API success. Report uncertain outcomes instead of presenting made-up confidence. Verify results with repeatable offline tests.
