# Git workflow
Each agent uses only its assigned feature branch, created from the same approved foundation commit. Do not merge docs into any code branch. Commit one verified logical increment at a time using a concise natural subject (e.g. 'Add catalog filters'), with no body, co-author trailer or AI signature. Preserve actual Git author metadata. Do not amend published commits, rewrite history, force push or edit main. Push your branch and open a PR; the integrator reviews and merges PRs one at a time, running CI after each. Check the changed-file list against ownership before every commit.
